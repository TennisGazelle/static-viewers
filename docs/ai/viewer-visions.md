# Viewer visions

This file is the index for the intent behind each standalone viewer. Detailed source/mapping documents remain authoritative where they exist.

## Color Atlas

**Question:** How many words is this color worth?

A provenance-aware atlas of color language projected through multiple mathematical color spaces. The same named points should remain traceable while the geometry changes, exposing both color science and the strange density of human naming.

Detailed vision: [color-atlas-vision.md](./color-atlas-vision.md).

## Star Wars Musical Themes

An explorable graph of the musical ideas and relationships documented in Frank Lehman's *Complete Catalogue of the Musical Themes of Star Wars*. The viewer should preserve the catalogue's taxonomy and uncertainty rather than inventing a cleaner ontology.

Detailed data/source vision: [STAR_WARS_DATA_MAPPING.md](../../STAR_WARS_DATA_MAPPING.md).

## Oppenheimer Plot Map

A spatial aid for understanding the screenplay/film's deliberately non-linear chronology. It should make temporal structure easier to inspect without flattening the story into a conventional linear synopsis.

The screenplay under [docs/reference](../reference/) is reference material. A dedicated source-to-view mapping document should be added when this viewer next receives substantial data work.
